# CODSOFT Calculator

## Overview

A professional, responsive, and accessible calculator built as part of the CODSOFT Web Development Internship. The calculator features a clean, modern UI with a focus on usability across all devices.

## Features

- **Basic Arithmetic**: Addition, subtraction, multiplication, division.
- **Advanced Functions**: Percentage calculations.
- **Input Handling**: Support for decimal numbers and large numbers.
- **State Management**: Robust state handling without using `eval()`.
- **Keyboard Support**: Full keyboard accessibility for seamless input.
- **Error Handling**: Graceful error handling (e.g., division by zero).
- **Responsive Design**: Mobile-first design that scales perfectly across all screen sizes.
- **Accessibility**: Semantic HTML, ARIA labels, and reduced motion support.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run

1. Clone or download the repository.
2. Navigate to the `Task-3-Calculator` directory.
3. Open `index.html` in any modern web browser.

No build process or external dependencies are required.

## Keyboard Shortcuts

- `0`–`9`: Number input
- `.`: Decimal input
- `+`, `-`, `*`, `/`: Operators
- `%`: Percentage
- `Enter` or `=`: Equals / Calculate
- `Backspace`: Delete last digit
- `Escape`: Clear all (AC)

## Responsive Design

The application is meticulously designed to work on:
- Mobile devices (320px to 425px)
- Tablets (768px)
- Laptops and Desktops (1024px and above)
