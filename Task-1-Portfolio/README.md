# Divyansh Verma — Developer Portfolio

This is a premium personal portfolio website for Divyansh Verma, an AI & ML Student and Software Developer. Built as part of **CODSOFT Web Development Internship — Level 1 Task 1: Personal Portfolio**.

## Overview
The website is designed to be a high-quality, professional developer portfolio focusing on:
- Software Engineering & Full-Stack Development
- Artificial Intelligence & Machine Learning
- Clean, semantic HTML structure
- Premium aesthetic with a dark-theme UI and custom conceptual SVG visuals
- Accessibility and Responsive design
- No reliance on heavy frameworks (Built with Vanilla Web Technologies)

## Features
- **Responsive Design**: Mobile-first architecture scaling seamlessly up to ultra-wide displays.
- **Custom Visual Identity**: Unique "DV + AI" SVG conceptual hero visualization and dashboard visuals.
- **Accessible Interactions**: Keyboard-navigable custom modals, ARIA-enabled mobile menu, and semantic HTML elements.
- **Scroll Reveal**: Lightweight `IntersectionObserver` animations (with respect to `prefers-reduced-motion`).
- **Performance Optimized**: Zero external JavaScript libraries, minimal CSS, inline SVGs.

## Technologies Used
- HTML5
- CSS3 (Custom Properties, Flexbox, CSS Grid)
- Vanilla JavaScript (ES6)

## How to Run Locally
1. Clone this repository or download the source files.
2. Ensure you have the required `Divyansh-Verma-Resume.pdf` file placed in the `assets/resume/` directory.
3. Open `index.html` in any modern web browser.
*(No build tools, node modules, or local servers are required to view the site, though a live server extension is recommended for local development).*

## Sections
1. **Header**: Sticky accessible navigation.
2. **Hero**: Introduction, primary CTA, and custom DV + AI visual.
3. **About**: Concise professional biography and focus areas.
4. **Skills**: Personal technical skills mapped into specific domains (Programming, Core CS, Web, AI/ML).
5. **Projects**: Detailed showcase of selected work (`EduTrack`, `AQI Prediction`, `Hotel Management`).
6. **Experience & Education**: Timeline of professional and academic journey.
7. **Contact**: Quick links for email and professional profiles.
